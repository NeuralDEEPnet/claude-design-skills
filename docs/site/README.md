# Site pages

Self-contained HTML pages for neuraldeep.net. No external fonts, scripts or images, so each file works as a Wix HTML embed (Add → Embed Code → Embed HTML, paste the file) or as a standalone page on any host.

| File | Purpose |
|---|---|
| `design-receipts.html` | "Design with receipts": what a Design Receipt is, a real review receipt as the example, who it is for, how to get it. Light and dark themes follow the visitor's system setting. |

Numbers on the page are computed with the WCAG 2.x formula against the eval page in `evals/cases/review-with-receipt`. Keep them in step if that page changes.

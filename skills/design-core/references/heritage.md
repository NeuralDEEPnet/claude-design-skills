# Heritage — classics as working lenses

A lens, not a style. Ids: `WB BR SW BO AW PG PL OL` + claim id (`docs/heritage/verified-research.md`); rows: `references/heritage-ledger.md`. Roles: [evidence] [opinion] [trend] [inspiration] [inference]; Take, checks, Carry forward = [inference].

## Rapid card
**Gate.** Read this file only if the brief names a tradition, school, designer, company, typeface or award, or asks for an award or "good design" review. Adjective-only briefs ("timeless", "clean", "premium") do not open it.
**At Rapid:** none named = read nothing, add no steps; named = this card plus one strand card.
**Reply, at most 60 words:** (1) one strand line: phase/team/edition, "not a look"; (2) one trap as an anti-principle; (3) one check: web/CAD = measured value + basis tag; image/motion/world = one yes/no rubric question [inference, simulated reviewer].
Say "inspired by", never "X style". Ledger only for a date, attribution, quote or number not on a card. A named tradition is a stated style: clean default off; lean delivery and reduction pass on; client identity wins.

## Operating rules
- Name the strand and phase; take the principle, not the period device. Each reference gets a `Becomes` cell (`templates.md`): a DNA principle with a rejection example, or a check below; else delete it.
- One accent, one family, two weights, the 8 px step: studio heuristics, never the classics'.
- Dates, attributions, quotes, numbers, criteria only from a card or ledger row, else omit or [inference]. Braun, Vitsoe, Rams, B&O, iF, Red Dot, MoMA, Helvetica are third-party marks: no endorsement. Never bundle Helvetica, Helvetica Neue, Arial or Nimbus Sans (naming it in a fallback stack is fine).
- No scoring; no "P#" labels. Every tunable carries a basis tag: [standard: <name>] [platform-fixed] [house heuristic] [brief].

## Strands
### Werkbund–Bauhaus
Dessau 1925 programme (Gropius): typical forms, economy, prototypes for industry; ornament only if functionally justified [evidence, WB c15-c18].
Take: function list first; types plus a variation space.
Trap: primary-colour geometric look; "Bauhaus = minimal"; Gropius 1968 rejected a fixed look [opinion, WB c23].
Checks: C1 C2 C3

### Braun–Eichler–Rams
Team language: Eichler, Gugelot, Aicher, Wagenfeld, Hirche, Rams [evidence, BR c9 c11]. Atelier 1/L1 "same proportions as the SK4" [BR added].
Take: purpose, order, family compatibility.
Trap: white box + orange accent; an invented grid (Moss 1962 gives none [BR c24 c25]).
Checks: C1 C2 C3

### HfG Ulm–Aicher
Ulm 1953-68 [evidence, BR c28 c31]. Munich 1972 pictograms on a vertical-and-diagonal grid [BR c33 c34].
Take: system plus method; declare, then measure.
Trap: a grid that only looks consistent: Holt 2025 found uneven limb thickness [opinion, second-hand, BR c35].
Checks: C2 C3

### Swiss / International Typographic Style
Müller-Brockmann, Grid Systems 1981: fields = whole text lines; 4x13+3=55 [evidence, SW c2 c3].
Take: fields derived from a declared line pitch.
Trap: equating Swiss with Helvetica [SW c11]; crediting him a baseline grid, two-weight cap [SW c6-c8] or golden module [SW c4].
Checks: C2 C3

### Helvetica
Neue Haas Grotesk 1957, renamed c.1959-61 [evidence, SW c18]; "neutral" (MoMA 2007) is disputed [opinion, SW c23 c26 c27].
Take: pick a face for a stated job; open stack Inter, OFL [SW c28]; Arimo/Liberation are Arial-metric [SW c29].
Trap: calling it neutral; bundling it.
Checks: C3

### Bang & Olufsen
Counter-evidence: iFixit rated Beoplay Eleven 1/10 [evidence, BO c30]; Beosound 9000 faults: one enthusiast source [BO c19 c20].
Take: tiered controls, off-state, reveal only for a named task.
Trap: ceremony as decoration; "B&O is Bauhaus" is company framing [BO c8].
Checks: C4a C4b C1

### iF / Red Dot / Good Design
Criteria are vocabulary, not authority: jury judgment on paid, self-selected entries [AW pitfalls]; Ohl's 768 criteria unused from 1983 [AW added].
Take: edition-stamp criteria (see ledger).
Trap: numeric scoring; promising a win.
Checks: C5b C5a

### Proportion systems
Declared families: √2/ISO 216 [PG c9-c11], Renard ISO 3 [PG c15-c17], Modulor [PG c12-c14]; see `references/proportion.md`.
Take: declare one family; measure per C2.
Trap: Parthenon is about 2.25, not phi [PG c4]; R10 is 1.259, not 1.25 [PG c15-c17].
Checks: C2

### De Stijl–Constructivism
Manifesto Nov 1918: balance of universal and individual, no palette or angle rule [evidence, OL ds1 ds2].
Take: declared vocabulary; flip test for balance.
Trap: "primaries on a grid"; "diagonals = Constructivism" (3+ formal tendencies [inference, OL cv2-cv5]).
Checks: C2 C1

### Olivetti–Vignelli
Olivetti 1954 jury cites "stylistic coherence" across graphics and shops [company archive, OL ol1-ol4]. Vignelli Canon 2010: "half a dozen" typefaces per career [OL vg1-vg3].
Take: one system across touchpoints via shared tokens.
Trap: a per-project cap of two typefaces.
Checks: C5a C2

### Klint–Super Normal–Muji–Eames
Klint: measure human dimensions, start from existing types [evidence, OL kl1]. Super Normal 2007: defined through use [opinion, OL jp2 jp3].
Take: dimension provenance (quantity, source, tolerance); precedent per control; constraint-to-form ledger (Eames leg splint 1941-42 [OL us1]).
Trap: "Super Normal = Muji look"; unsourced slogans.
Checks: C2 C4a C1

## Checks
Each: test · fails when · basis. Untagged = [house heuristic]; tunables are declared in the brief, none is the classics' doctrine.

C1 Purpose ledger + remove-one. Test: name each element's function BEFORE removing it; remove singly; re-run the task; a fresh reader with labels masked names function and primary action [inference, simulated reviewer]. Fails when: an element stays on a post-hoc "brand" reason, or removal changes nothing.

C2 Declared set, then measure. Test: one row per medium (web tokens; image grid, crops; 3D dimension, radius families; motion duration ramp, easing family; world scale anchors); residue per value; named ratio within 1% [house heuristic] or "approximately"; [platform-fixed] exempt. Fails when: an outlier has no function or fix, or a ratio claim is over 1% off unqualified.

C3 Reproduction-loss. Test: render at 320 px [standard: WCAG 1.4.10] plus two widths [brief], greyscale, one-colour/print, final crops, light/dark, WCAG 1.4.12 overrides (line height 1.5, paragraph 2x, letter 0.12 em, word 0.16 em [standard: WCAG 1.4.12]). Fails when: meaning or primary action is lost, state relies on colour alone, or an override clips content (fixed-height boxes, tight leading).

C4a Tiered controls, idle/off state. Test: name the top 3 tasks [house heuristic]; no primary control hidden; hidden ones get a visible cue and a non-motion path; render with emissive elements off, name the alignment lines. Fails when: a primary control is hidden, a hidden one lacks cue or path, or no alignment line can be named.

C4b Reveal spec, repair evidence. Default: none. Test: remove the motion; if no named task needs it, drop it. Kept: specify closed/moving/open/blocked/power-lost, obstruction response, manual fallback. Repair: parts list, fasteners, procedure, availability period, or "unknown". Fails when: the reveal serves no task, a state or fallback is missing, or repairability is claimed without evidence.

C5a Differentiation by structure. Test: comparator table with URLs; tag each difference structural or surface; second reviewer [inference, simulated reviewer]. Fails when: all differences are surface or a comparator lacks a URL.

C5b Award readiness. Test: edition-stamp criteria; ask first for existing evidence (CAD, prototype, tests, certificates, accessibility review); per criterion: in hand / to produce / not applicable, no scores; name what schemes do not test (user evidence, accessibility conformance, performance, safety certification [inference, AW c35 c36]); promise no win; safety conformity is the maker's duty; no invented user research, offer a labelled template. Fails when: scores or odds appear, or evidence is invented.

Passing shows self-consistency with the declared rules, not quality or lineage authenticity.

## Tensions
Surface only live ones (Standard: at most 3); take the default; a blocking fork counts toward the 3-question limit. Rows: collision | default | reverses when.
- Client identity vs house style | client wins; tradition gives principles | client drops it
- Standardisation vs individuality | types + variation space [WB c16-c18] | brief needs a one-off
- Neutrality vs warmth | face/material for the job; never "neutral" | brief wants warmth or clinical register
- Reveal vs restraint | no reveal (C4b) | a named task needs it
- Award criteria vs evidence | plan evidence; claim nothing | evidence exists
- Economy vs accessibility | economy = fewer decisions, never fewer functions | tested need shows a cue is redundant
- Disputed dates | give the range with sources | needs one date: name the source

Settled by fact: Sullivan coined "form follows function", 1896 [WB c20]; Bauhaus had no single look or dogma; Parthenon is about 2.25, not 1.618; 1970 NYC manual: Standard Medium, not Helvetica [SW c24]. At Full, a tension can be the divergence axis: two concepts at its poles, one refusing it.

radius/angle: _ [house heuristic]; hues: _ + neutrals [brief]
exempt:       44 pt iOS [platform-fixed, PG c24]
thresholds:   ratio within 1%; type within ±0.5 px [house heuristic]

Residue: `min(v mod u, u − v mod u)`. After the build, measure every literal; outliers: value · measured · function or fix. Necessary, not sufficient. Full: perturb u; list literals that did not move.
